# Biology worksheet photos

Two synthetic worksheet photographs generated with the built-in image generation tool for photo-import and vision testing. Both have five unanswered biology questions. Copies are installed in the test emulator under `Pictures/SchoolHelp` and indexed in its photo library.

- `cells-and-photosynthesis.png`: plant/animal cell structures, mitochondria, photosynthesis, starch in darkness, released gas.
- `genetics-and-inheritance.png`: genes, genotype/phenotype, Tt inheritance, human chromosomes, sexual reproduction.

In SchoolHelp, choose **Import photo** and select either worksheet. Use OpenRouter with your own key for emulator solving; evaluate Gemma GPU inference on a physical phone.

The exact generation prompts are in `prompts.txt`.
